# HOVEL Product Review Database

HOVELの商品レビューを、単発記事ではなく事業資産として蓄積するためのデータベースです。

## 目的

- どの悩みに対して、どの商品が有効だったかを記録する
- note記事、X投稿、アフィリエイト成果を1つのIDで接続する
- 購入前・初回使用・7日・30日の評価変化を残す
- 売れた商品ではなく、読者の問題解決に寄与した商品を特定する

## 主ファイル

`product_review_db.csv`

1商品1行で管理します。レビューの進行に合わせて既存行を更新します。

## review_stage

- `pre-use`: 購入前または未使用
- `day-1`: 初回使用後
- `day-7`: 7日使用後
- `day-30`: 30日使用後
- `closed`: 検証終了

## confidence_level

- `low`: 公開情報または短期使用だけ
- `medium`: 複数回使用し、使用条件も記録済み
- `high`: 30日程度の使用、比較対象、欠点、成果データまで確認済み

## decision

- `test`: 検証継続
- `recommend`: 条件付きまたは積極推奨
- `hold`: データ不足で保留
- `reject`: 推奨しない
- `retire`: 取扱終了、仕様変更、または検証対象外

## 運用ルール

1. 未使用の商品について、性能を断定しない
2. メリットとデメリットを両方記録する
3. 健康・衛生に関する主張は根拠確認と人間承認を必須にする
4. アフィリエイト成果が高くても、読者価値が低い商品は推奨しない
5. Amazonクリックや注文が0でも、未計測と0を区別する
6. 商品名変更や別容量は、比較可能性を確認して別IDにする

## ファネル接続

```text
Xの悩み仮説
→ noteの解決記事
→ 商品レビュー
→ アフィリエイトクリック
→ 注文・収益
→ 継続・改善・停止判断
```

## 最初の検証対象

Old Spice 2-in-1 Shampoo & Conditionerを`PR-0001`として登録済みです。購入後にDay1、Day7、Day30の順で更新します。
