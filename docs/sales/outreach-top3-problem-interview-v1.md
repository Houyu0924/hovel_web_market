## 1. InfraAcademy

### 接触理由
2026-07-24に法人向けインフラ研修eラーニング「InfraAcademy 法人プラン」を開始。Linux・ネットワーク・AWS等の教材、ブラウザ演習、学習管理をまとめ、5ID・月額30,800円（税別）から提供。

### HOVELの仮説
新規法人プランでは、価格そのものよりも「どの会社・どの教育課題に最も刺さるのか」「実践環境の価値をどう伝えるか」「既存研修・動画教材との違いをどう理解してもらうか」が初期の学習ポイントになりやすい。

### 初回接触文
突然のご連絡失礼いたします。HOVELの○○と申します。

InfraAcademy 法人プランの提供開始を拝見しました。教材だけでなく、Linux・AWS・ネットワークの実践環境や学習管理までWeb上で完結する点が特徴的だと感じています。

現在HOVELでは、新しく法人向けサービスを立ち上げた企業に対して、営業量を増やす前に「どの顧客に、どの価値が刺さり、どこで導入が止まるのか」を一次情報から整理するCustomer Understandingの検証を進めています。

もし差し支えなければ15分ほど、
- 想定より反応が良い企業像
- よく聞かれる質問
- 価格への反応
- 説明し直すことが多いポイント
- 導入時に止まりやすい理由

についてお話を伺えないでしょうか。

今回はサービス販売のご提案が目的ではなく、法人プラン立ち上げ直後の顧客理解で何が実際に難しいのかを確認したく、ご連絡しました。

## 2. Saix

### 接触理由
2026-07-25に法人向けSaaS「Saix AIマニュアル Studio」を発表し、2026年8月から先行導入企業の相談受付を開始。マニュアル作成、検索、AI FAQ、教育、理解度テスト、育成ダッシュボード、改善までを一体化。

### HOVELの仮説
提供価値が広いため、顧客によって「属人化解消」「新人教育」「引き継ぎ」「FAQ削減」「マニュアル作成時間削減」のどれが主Problemになるかが分かれやすい。多機能さが強みである一方、初回商談では価値の焦点がぼやける可能性がある。

### 初回接触文
突然のご連絡失礼いたします。HOVELの○○と申します。

「Saix AIマニュアル Studio」の先行導入開始を拝見しました。マニュアル作成だけでなく、AI FAQ、教育、理解度確認、改善まで一体化している点が非常に興味深いです。

一方で、機能が広いサービスほど、見込み顧客によって「属人化解消」「新人教育」「引き継ぎ」「問い合わせ削減」など、最も刺さる価値が分かれやすいのではないかと考えています。

HOVELでは現在、新規B2Bサービスについて、営業量を増やす前に「顧客が何を買っているのか」「どこで理解が止まるのか」を一次情報から整理するCustomer Understandingの検証を進めています。

もし差し支えなければ15分ほど、
- 相談企業が最初に持ち込む課題
- 特に反応が良い利用場面
- 説明しても伝わりにくい点
- 比較される代替手段
- 導入判断で止まりやすい理由

を伺えないでしょうか。

今回は営業提案が目的ではなく、先行導入フェーズで顧客理解のどこが難しいのかを確認したく、ご連絡しました。

## 3. sai X aid / lead X aid

### 接触理由
2026-08-01からAI営業エージェント「lead X aid」の新料金プランを開始。国内115万社の企業データベースを標準搭載し、企業リスト、文面作成、送信を一体化。月額5万円〜25万円の4段階。

### HOVELの仮説
新料金の強みは「リスト別売り不要」「1通2.5円〜10円」「初期費用0円」だが、購買判断では単価だけでなく、送信品質・返信率・商談化・既存営業手段との比較が重要になる可能性が高い。価格訴求と成果訴求のどちらを前面に出すべきかが主要なCustomer Understandingテーマ。

### 初回接触文
突然のご連絡失礼いたします。HOVELの○○と申します。

lead X aidの新料金体系を拝見しました。企業データベース、文面作成、送信まで一体化し、リストの追加購入を不要にした設計が分かりやすいと感じています。

料金体系を変更した直後は、「安さが決め手になるのか」「リスト込みが刺さるのか」「最終的には返信・商談化への期待で判断されるのか」など、顧客が実際に買っている価値を見極めるタイミングだと考えています。

HOVELでは現在、新規・料金変更直後のB2Bサービスについて、顧客の一次情報から「何が刺さり、どこで導入が止まるのか」を整理するCustomer Understandingの検証を進めています。

もし差し支えなければ15分ほど、
- 新料金への反応
- 最も刺さる価値訴求
- よく比較される代替
- 導入前に出る不安
- 価格以外で止まる理由

を伺えないでしょうか。

今回は営業提案が目的ではなく、料金変更直後の顧客理解で何が難しいのかを確認したく、ご連絡しました。

## 共通ルール

- 初回は売らない。
- 15分だけ依頼する。
- 「御社の課題はこれです」と断定しない。
- 公開情報から仮説を1つ持って入る。
- 相手の答えをProblem / Desire / Barrier / Price / Alternative / Decisionに分類する。
- 会話後、相手が課題を強く認識している場合のみPilot提案へ進む。
