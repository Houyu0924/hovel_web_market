# HOVEL Customer Understanding Sprint — 有料Pilot提示文 v1

Date: 2026-08-09
Status: Ready to use

## 使うタイミング
Problem Interviewで「売れない理由が分からない」「顧客の反応が曖昧」「価格・訴求・ターゲットの判断に迷う」と確認できた後だけ使う。

## 口頭/メール共通の短文

ありがとうございます。お話を伺う限り、現時点では営業量を増やす前に、
**『誰に何が刺さっていて、どこで購入が止まっているか』を一次情報で確認する価値がありそう**です。

HOVELでは、7〜10日で小規模なCustomer Understanding Sprintを行っています。

### Pilot内容
- 対象テーマ: 1テーマ
- 対象者: 5名を目安
- 既存の営業/失注情報も可能な範囲で確認
- 競合・代替の公開情報も補助的に確認
- 納品: Decision Memo 1枚 + 回答要約

### 納品で決めること
1. 実際に求められている価値
2. 主な購入障壁
3. 価格に対する反応
4. 競合/代替との比較軸
5. 優先ICP
6. 次に変えることを最大3つ

改善案は、
`Evidence → Insight → Decision → Validation`
の形で整理します。

### Pilot価格
**30,000円**

初期Pilotのため、終了後に短いフィードバックをいただけることを条件としています。
公開事例化については、事前に個別に可否を確認し、許可なく社名・内容を公開しません。

もし進める場合は、対象テーマを1つ決めたうえで、見積書をお送りします。

---

## 言わないこと
- 「必ず売上が上がります」
- 「CVRを改善します」
- 「競合より優れています」
- 実測前の成果保証

HOVELが約束するのは、**一次情報と既存データを整理し、次に何を変えるかを判断できる状態にすること**。
