# HOVEL ニッチ市場アフィリエイト Side Lane v1

更新日: 2026-08-09

## 結論

ニッチ市場アフィリエイトは **別軸で採用する。ただし本命事業ではなく、運営資金づくり + 市場学習 + Distribution獲得のSide Laneとして扱う。**

目的は3つ。

1. 少額でも自己資金を作る
2. どのProblem/検索意図/比較軸でコンバージョンするか学ぶ
3. 将来のData Platform / Databaseの初期集客資産を作る

## 採用条件

以下を満たす案件だけ扱う。

- 高単価または継続報酬
- 検索者の購買意図が強い
- 比較軸を構造化できる
- 競合が大手メディア一色ではない
- HOVEL本命のデータ資産に転用可能
- 1記事ごとの労働集約ではなく、比較表/診断/DBとして再利用できる

## やらないこと

- 雑記ブログ
- 低単価物販
- PV依存の大量記事SEO
- 流行だけの短命キーワード
- 医療・金融など高い専門責任を伴う領域を安易に扱う
- 成果報酬だけで本命事業の成立を判断する

## 初期Vertical候補

### A. 法人向けAI研修 / AI人材育成

理由:
- 比較意図が強い
- 価格差が大きい
- 導入目的/対象者/支援範囲で比較軸を作りやすい
- 将来の法人AIサービスDBへ接続可能

### B. 中小企業向け会計・バックオフィスSaaS

理由:
- 継続課金商材が多い
- 比較ニーズが強い
- freee Labで既存学習資産がある
- 将来の業務SaaS比較DBへ接続可能

### C. 営業支援 / CRM / 営業AI

理由:
- B2B単価が高い
- ROIと比較軸が明確
- Trigger / Competitive Intelligence事業とも接続しやすい

## MVP

1 Verticalだけ選ぶ。

最初に作るのは記事10本ではなく、以下の1セット。

1. 比較DB 20〜30社
2. 条件別比較表
3. 5問程度の選定診断
4. 「誰に向く / 向かない」ページ
5. 3本だけ高購買意図ページ
6. Affiliate CTA
7. クリック/CV計測

## KPI

North Star:
**比較・診断経由のAffiliate Revenue per 1 hour of maintenance**

補助KPI:
- 診断完了率
- Affiliate CTA CTR
- EPC
- CVR
- 1件あたり報酬
- 月間保守時間
- データ再利用率

## 4週間の判断基準

継続:
- Affiliate CTAクリックが発生
- 購買意図の強い検索/流入パターンが見える
- DB/比較データを本命事業にも転用可能

縮小/停止:
- 更新作業が週5時間を超える
- 報酬単価が低い
- 成果条件が不安定
- 集客が記事量産に依存する

## 位置づけ

本命:
Data Asset → Database → Comparison / Lead Gen → Premium Data → API

Side Lane:
Affiliate → 低コスト資金化 + 市場学習 + Distribution

Side Laneが本命の可処分時間を侵食したら停止する。

## 次の1タスク

A/B/Cの3Verticalについて、
- 案件数
- 報酬単価
- 継続報酬の有無
- 競合強度
- 比較軸の作りやすさ
- 本命データ資産への転用性
を調査し、1つに絞る。
