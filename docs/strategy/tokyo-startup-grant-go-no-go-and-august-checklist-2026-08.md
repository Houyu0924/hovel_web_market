# HOVEL 東京都創業助成事業 Go / No-Go判定 & 8月チェックリスト

更新日: 2026-08-09

## 結論

現時点は **条件付きGO**。

HOVELは、
- 開業届未提出
- 経営経験通算5年未満
- GビズIDプライム未取得
- マイナンバーカード保有

のため、創業前個人としての申請可能性を残しつつ、申請要件2を満たせるかを最優先で確認する。

本助成事業は申請要件1〜4すべてを満たす必要があり、申請要件2は公式に「概ね3か月以上かかる」と案内されているため、8月中の着手がボトルネック。

## Go条件

以下を満たせるなら令和8年度第2回へGO。

- [ ] 申請要件2を満たす支援ルートに期限内に着手できる
- [ ] 2026-09-29〜2026-10-08のJグランツ申請に間に合う
- [ ] GビズIDプライムを取得できる
- [ ] 都内で創業予定、または対象となる事業者要件を満たす
- [ ] HOVELの事業計画を1本に絞って申請書へ落とせる
- [ ] 助成対象経費が「売れる前提の自動化投資」に使える

## No-Go条件

以下のどれかに該当したら、第2回への無理な申請はしない。

- [ ] 申請要件2の達成が期限上困難
- [ ] 助成金に合わせて事業内容を歪める必要がある
- [ ] 申請準備により事業検証・資金獲得が止まる
- [ ] 採択前提で支出計画を組まなければ成立しない

No-Goの場合は次回公募を狙い、Customer Cash / Corporate Credits / 小額アフィリエイト収益を優先する。

## 8月中チェックリスト

### P0: 今週

- [ ] TOKYO創業ステーションのプランコンサルティングへ申込
- [ ] 令和8年度第2回の申請要件2の達成ルートを相談員に確認
- [ ] GビズIDプライム申請
- [ ] HOVELの申請事業を「レバレッジ型WEBマーケティング事業」1本に仮固定
- [ ] 事業計画の骨子: 顧客 / Problem / Solution / 収益 / 集客 / 競争優位 / 3年計画

### P1: 8月中旬

- [ ] 顧客候補10名へのProblem Interview
- [ ] 支払意思の確認
- [ ] MVPを無料/低コストで再現する方法を確定
- [ ] 必要経費を「検証前」「検証後」に分離
- [ ] 助成対象候補経費を整理: 広告、市場調査、備品、専門家等

### P2: 8月後半

- [ ] 収支計画をBase / Conservative / Upsideの3ケースで作る
- [ ] 助成金なしでも成立する資金計画を作る
- [ ] 助成対象経費の見積候補を準備
- [ ] 審査で問われる市場性・実現性・継続性のEvidenceを準備
- [ ] Jグランツ申請に必要なPDF化・添付物を確認

## 資金調達ルール

優先順位:

1. Customer Cash
2. Corporate Credits
3. Grants / Subsidies
4. Debt
5. Equity

助成金を「開始条件」にしない。
