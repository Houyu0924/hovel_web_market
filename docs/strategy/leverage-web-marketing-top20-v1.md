## 最重要候補 5案

### A. 企業Trigger API
公開情報から「新サービス、価格変更、法人プラン、採用強化、資金調達、LP変更」等を検出し、営業・マーケ担当に提供。

- 強み: データが蓄積資産になる
- Monetization: 月額SaaS / API / White-label
- 初期MVP: 手動収集 + スプレッドシート + メール配信でも検証可能
- 顧客候補: 営業支援会社、B2B SaaS、広告代理店、コンサル
- Key Question: 「新しい営業先」ではなく「今買う理由がある会社」に企業は払うか

### B. 競合LP変更監視SaaS
競合の価格、訴求、CTA、機能、事例ページの変更を自動監視し、重要差分だけ通知。

- 強み: 明確な反復利用
- Monetization: 月額1〜10万円、監視社数/頻度別
- 初期MVP: URL監視 + 差分抽出 + AI要約
- 顧客候補: SaaS、D2C、広告代理店、PMM
- Moat: 長期変更履歴

### C. AI検索ブランド露出監視SaaS
ChatGPT、Gemini、Perplexity等の代表質問群で、自社/競合がどう説明・推薦・引用されるかを追跡。

- 強み: 新カテゴリで予算化余地がある
- Monetization: 月額 + 監視クエリ数
- 初期MVP: 固定プロンプト群の定点計測レポート
- 顧客候補: SaaS、EC、マーケ支援会社
- リスク: 各AIサービスの仕様・規約変更依存

### D. 営業会話→マーケ改善AI
商談録音/文字起こしから、反論、欲求、競合、価格抵抗を抽出し、LP・FAQ・営業資料の改善案を返す。

- 強み: First-party dataに直接接続
- Monetization: 月額/商談数課金
- 初期MVP: 文字起こしファイルアップロード型
- 顧客候補: B2B SaaS、研修、BPO
- Moat: 顧客別の会話履歴と改善履歴

### E. 失注理由自動分析SaaS
CRM、失注メモ、商談記録から「なぜ負けたか」を継続分類し、価格/競合/機能/社内承認等の変化を検出。

- 強み: 売上に近い課題でROI説明しやすい
- Monetization: 月額 + CRM連携
- 初期MVP: CSVアップロード型
- 顧客候補: B2B SaaS、高単価法人サービス
- Moat: 失注理由の時系列DB

## 20案に残した共通条件
- ストック型データまたは履歴が残る
- 月額・API・利用量課金に移行できる
- MVP段階では人力やAIオペレーションで代替可能
- 初期顧客10社を取る前に大規模開発しなくてよい
- SEOトラフィックだけに依存しない

## 落とした主なタイプ

### 純メディア/SEO依存
検索流入のゼロクリック化・AI回答化で構造的リスクが高い。独自データや取引機能がなければ優先しない。

### Marketplace単独
ネットワーク効果は強いが、初期の両面市場立ち上げコストが高い。顧客基盤を先に持ってから検討。

### テンプレート/教材単独
粗利は高いが防御力とLTVが弱い。SaaSやデータ商品の獲得チャネルとしてのみ検討。

### 汎用AI Agent
競争が激しく、単なるAIラッパーでは差別化しにくい。固有データ・固有ワークフローがある案だけ残す。
