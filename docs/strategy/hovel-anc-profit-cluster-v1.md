# HOVEL ANC収益クラスター v1

更新日: 2026-08-08

## 方針

耳栓は主戦場から外す。騒音対策はノイズキャンセリングイヤホン（ANC）を中心に再設計する。

ただし、Amazonの家電カテゴリ紹介料率は2%のため、ANC単体をAmazonアフィリエイトだけで年間利益1,000万円の柱にはしない。
ANCは以下の目的で使う。

1. 高単価購買意図の検証
2. 会社員向け条件付き比較による差別化
3. ASP・メーカー直販・ECモール・BtoB導線の探索
4. 集中・会議・通勤・PC環境など高単価Problemへの入口

## 選定基準

記事テーマは以下で評価する。

- 需要
- 1CV利益
- 棲み分け余地
- 継続需要
- 周辺商材への横展開
- BtoB/自社商品への接続

## 収益上の注意

- Amazon家電の標準紹介料率は2%なので、4万円の商品でも単純計算では約800円/件。
- したがってAmazonのみで利益を最大化しない。
- 記事公開時に、メーカー公式アフィリエイト、ASP、楽天/Yahoo等の報酬条件も確認する。
- BtoBヘッドセット、会議機器、AI議事録SaaS、業務効率化SaaSなど、1CV利益の高い周辺商材に接続する。

## 最初の検証記事

### 1本目

**電車通勤とオンライン会議を1台でこなせるANCイヤホン比較**

理由:

- 使用シーンが明確
- 高単価商品の比較意図がある
- 通勤・会議の2Problemを同時に解決

- 周辺記事を展開しやすい
