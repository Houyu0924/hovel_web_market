# HOVEL 運転資金300万円づくり：Vertical選定 v1

目的：2026-09〜2027-08の12か月で、レバレッジ型本業の開発・運営に回せる運転資金300万円を作る。

前提：
- 本業は将来のData Platform / Database / APIに接続すること。
- 初期投資は最小化する。
- 単発受託ではなく、同じ調査・情報資産を複数社へ再販売できること。
- 月次の可処分時間を圧迫しないこと。

## 評価軸（各5点）
1. スポンサー候補数
2. スポンサー単価余地
3. 情報更新頻度
4. 公開情報だけで価値あるDBを作れるか
5. 将来の比較・送客・APIへの拡張性
6. 9月から販売検証しやすいか

## 採用Vertical

**バックオフィスAI / AIエージェント**を第一Verticalとして採用する。

対象カテゴリ：
- 経理AI
- 労務AI
- 総務AI
- 法務AI
- バックオフィスAIエージェント
- AI BPO
- 業務自動化 / ワークフローAI

## 採用理由

### 1. 売り手が多く、スポンサー候補を作りやすい
大手SaaS、AIスタートアップ、BPO、SIer、研修会社など、異なる予算源を持つベンダーが同じ購買市場を狙っている。

### 2. 変化が多い
AIエージェント、新機能、料金、対象業務、導入事例、連携サービスなど、継続更新するデータが多い。

静的な「おすすめ10選」ではなく、更新価値のあるDatabaseを作りやすい。

### 3. Buyerの課題が明確
主なBuyer：
- CFO / 経理責任者
- CHRO / 人事責任者
- 総務責任者
- DX責任者
- 情報システム部門
- 経営者

課題：
- 人手不足
- 定型作業
- 採用難
- 入力・照合・承認負担
- AI導入のROI
- SaaS乱立による選定困難

### 4. 情報資産を多重収益化できる
1回収集したデータを次へ再利用する。

`Vendor DB → 比較ページ → Buyer Guide → Sponsor枠 → Lead送客 → Premium DB → API`

### 5. 将来のData Platform本業と接続する
最初はメディア/Researchとして手動運営できるが、データが蓄積すると以下へ移行できる。
- 料金変更アラート
- 新サービス監視
- 導入事例DB
- カテゴリ別比較
- ベンダー向けMarket Intelligence
- API / Data Feed

## 300万円への基本シナリオ

目標は一社高単価ではなく、Research Assetを複数社に売ること。

例：
- Q1：Founding Partner 2社
- Q2：4社
- Q3：6社
- Q4：8社

平均5万円/月へ到達できれば、年間300万円規模の売上ラインに届く。

別途、以下を上乗せする。
- Sponsored Report
- Lead referral
- Affiliate
- Premium listing

ただし初年度は収益源を増やしすぎず、Partner売上をNorth Starとする。

## なぜ法人AI研修を1位にしないか

研修市場は新規参入が多く販売検証しやすい一方、研修内容のコモディティ化、助成金依存、年度・新人研修シーズン等の変動がある。

Side Verticalとして残すが第一Verticalにはしない。

## なぜ営業AIを1位にしないか

支払意思は強そうだが、製品価値を正確に比較するためにCRM連携・実利用・非公開機能への理解が必要になりやすい。

公開情報だけで高品質なDBを早期構築する難易度がバックオフィスAIより高い。

## 販売検証

最初のスポンサー候補20社を作り、以下を確認する。

質問：
- この市場情報を社内で現在どう集めているか
- 競合・価格・導入事例を継続把握する必要があるか
- 月次Briefに払えるとしたら何が必要か
- Sponsor / Premium Listing / Lead referralのどれに予算が出るか
- 月額3〜5万円は高いか安いか

## Kill Criteria

以下ならVerticalを撤退・変更する。
- 20社ヒアリングして有料関心0〜1社
- 競合情報を誰も継続的に必要としていない
- Sponsorより単発広告しか需要がない
- 毎週更新できる独自データが作れない
- 1社対応に月2時間超の個別作業が恒常化する

## 次のVertical

第一VerticalがKill条件に達した場合の順序：
1. 法人AI研修
2. 営業AI / Sales Tech
3. AI導入支援 / AI BPO

## Decision

**2026-08-09時点では、運転資金300万円づくりの第一Verticalを「バックオフィスAI / AIエージェント」にする。**

ただしこれはStrategy Lockではなく、9月の販売検証で支払意思が確認されるまで仮説扱いとする。
