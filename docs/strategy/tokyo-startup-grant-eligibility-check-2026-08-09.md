# HOVEL 東京都「創業助成事業」申請可否チェック 2026-08-09

## 結論

令和8年度第2回「創業助成事業」は、HOVELの運営資金候補として検討価値が高い。ただし、現時点では申請可否を確定できない。

最大のボトルネックは次の2点。

1. 指定された創業支援事業の利用実績（申請要件2）
2. GビズIDプライムの取得

特にプランコンサルティング経由で申請要件2を満たす場合、令和8年8月22日（土）までに相談開始が必要。現在日付は2026-08-09のため、残り期間が短い。

## 公募概要

- 申請受付：2026-09-29 10:00 ～ 2026-10-08 23:59
- 助成率：対象経費の2/3以内
- 上限：400万円
- 下限：100万円
- 事業費＋人件費の上限：300万円
- 委託費の上限：100万円
- 対象期間：交付決定日から6か月以上、最長2年
- 主な対象経費：賃借料、広告費、器具備品購入費、産業財産権、専門家指導費、従業員人件費、市場調査・分析費
- 申請方法：Jグランツのみ

重要：交付決定前に契約・履行・支払いした経費は、原則として助成対象外。補助金を前提に先に支出しない。

## 申請要件チェック

### 申請要件1：創業者属性・所在地等

現状：**確認不能**

公式上、主に以下が必要。

- 都内で創業を具体的に計画している個人、または創業後5年未満の法人・個人事業主等
- 代表者の経営経験が通算5年未満
- 他事業者からの事業承継・譲渡に該当しない
- 法人の場合：本店登記が東京都内
- 個人事業主の場合：個人事業税の納税地が東京都内

HOVEL側で確認する項目：

- [ ] 開業届提出済みか / 創業予定個人として申請するか
- [ ] 過去の個人事業主期間＋法人代表期間の合計が5年未満か
- [ ] 個人事業税の納税地を東京都内にできるか
- [ ] 既存事業の承継・譲渡ではないこと

注意：現在地が東京都内でも、申請要件上の「納税地・本店所在地」とは別。住所推定だけでは適格判定しない。

### 申請要件2：指定創業支援事業の利用

現状：**未確認 / 最優先**

23の指定ルートのいずれか1つを満たす必要がある。

現状もっとも現実的な候補：

**TOKYO創業ステーションのプランコンサルティング**

令和8年度第2回の終了証を狙う場合：

- 相談開始期限：2026-08-22（土）まで
- 事業計画書の担当相談員への提出期限：2026-09-12（土）まで
- 終了証発行には事業計画完成後、約3週間必要
- 初回相談から終了証まで平均3～4か月、早い場合でも約1か月
- 期限内でも事業計画が未完成なら終了証が間に合わない可能性あり

よくある未完成理由：

- 標的顧客が明確でない
- 顧客ニーズの仮説検証が不足
- 販売計画の根拠が不足
- 費用項目・収益性の検討不足
- 資金繰りがショートしている
- 収支計画と資金繰り表が不整合

HOVEL Action：

- [ ] 8/22までにプランコンサルティングを開始できるか確認
- [ ] HOVELの再選定中ビジネスを1案に絞り、事業計画の対象事業を固定
- [ ] 顧客、課題、競合、価格、販売計画、費用、資金繰りを1枚ずつ準備

代替ルート例：

- 認定特定創業支援等事業（都内区市町村）
- 東京商工会議所等の指定支援
- 東京都中小企業制度融資（創業）
- 一部アクセラレーションプログラム

ただし、各ルートで期間・採択・融資等の追加条件があるため、最短とは限らない。

## GビズID

現状：**取得状況不明**

Jグランツ申請にはGビズIDプライムが必要。

デジタル庁の現行案内では、個人事業主がマイナンバーカード＋対応スマートフォンを使ってオンライン申請する場合、最短即日発行が可能。

必要候補：

- マイナンバーカード
- PC等
- メールアドレス
- NFC対応スマートフォン
- GビズIDアプリ

Action：

- [ ] GビズIDプライム保有状況を確認
- [ ] 未取得ならオンライン申請可否を確認
- [ ] マイナンバーカード未保有等の場合は書類申請のリードタイムを考慮

## HOVELの資金戦略上の扱い

創業助成事業は「今日の運営資金」ではない。

理由：

- 交付決定前の支出は原則対象外
- 助成率は2/3で自己負担が必要
- 申請・審査・実施・支払確認を経て受給するため時間差がある

したがって資金源の順序は維持する。

1. Customer Cash
2. Corporate Credits
3. Grants / Subsidies
4. Debt
5. Equity

助成金の役割は、需要確認後の「広告・データ収集・設備・市場調査・人件費等の加速資金」。

## 直近の優先順位

### P0：今週

1. 申請要件1の4項目を本人確認
2. GビズIDプライムの取得状況確認
3. プランコンサルティングを申請要件2のルートに使うか決定
4. 使うなら8/22より十分前に初回相談を確保
5. 助成対象にする本命事業を再選定して固定

### P1：8月中

- 本命事業の顧客検証
- 12～24か月収支計画
- 資金繰り表
- 対象経費候補リスト
- 売上の根拠資料
- 競合比較
- 創業理由・市場性・優位性の文章化

### Go / No-Go

以下を満たした時だけ第2回申請を本格化する。

- 申請要件1～4を全て満たす見込み
- 申請要件2の証明書を期限内に取得可能
- GビズIDプライムが準備済み
- 本命事業が1案に固定されている
- 助成金なしでも最低限のMVP検証が可能
- 100万円以上の対象経費を合理的に説明できる

満たさない場合は、助成金のために事業を歪めず、次回公募または他制度へ回す。
