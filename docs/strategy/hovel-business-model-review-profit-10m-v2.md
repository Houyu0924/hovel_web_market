# HOVEL ビジネスモデル再検討 v2 — 利益1,000万円から逆算

Date: 2026-08-09
Status: Active Review
Owner: HOVEL

## 結論

現行の **Customer Understanding Sprint（3万円〜5万円）をそのまま大量販売して利益1,000万円を目指す戦略は弱い。**

ただし、捨てるべきなのは「顧客理解」という中核ではない。

見直すべきなのは以下。

1. 商品名が広すぎる
2. 顧客の緊急度が弱い
3. 価格の根拠が弱い
4. 継続契約に繋がる構造が薄い
5. 実績がない段階で“調査全般”を売ると信頼獲得が難しい

したがってHOVELは、

**広いCustomer Understandingを内部能力として持ちつつ、外向きには高価値のPoint Solutionから入る。**

- 2週間Sprint

- 正しいICPに直接聞く

- 勝敗理由をbuyerに直接聞く
- CRMや営業担当の推測ではなく第三者の一次情報を使う
- 単発だけでなく継続Programへ発展可能
- Revenue / GTMに直接結びつくため経営予算を取りやすい

### 日本市場

- BtoBマーケティングコンサルも月30〜50万円以上の価格帯が一般的に存在する
- よって「企業が顧客理解に払わない」のではなく、HOVEL側がどの予算項目を取りに行くかが問題

# 事業案比較

## A. 現行：Customer Understanding Sprint

### 長所
- 幅広いProblemを受けられる
- 初期学習には向く
- 顧客理解を横断的に蓄積できる

### 短所
- 何を買うサービスなのか一瞬で分かりづらい
- 3万〜5万円では利益1,000万円まで案件数が増えすぎる
- 顧客ごとに調査内容が変わり、標準化しづらい
- respondent sourcingまでHOVEL負担だと粗利が落ちる

### 判定
**内部のDelivery Frameworkとして維持。外向きの商品名にはしない。**

## B. 推奨Wedge：B2B Positioning & Message Validation Sprint

### 顧客
- B2B SaaS
- 法人向けAIサービス
- 法人研修 / B2B教育
- 新規法人向けサービス

### Trigger
- 新サービス公開
- 法人展開
- 新料金
- LPリニューアル
- 複数セグメントで訴求がぼやけた
- 商談はあるが差別化が伝わらない

### 顧客が買う問い

**「誰に、何を、どう言えば売れやすくなるのか？」**

### 納品
1. 現状Positioning診断
2. ICP仮説
3. 競合 / 代替比較
4. 見込み顧客5〜8名の一次情報
5. 3〜5個のPositioning Option
6. Message Validation
7. 推奨Positioning
8. LP Hero / Value Proposition案
9. 次に変える3つ

### 価格ロードマップ
- Founding Pilot：3万円〜5万円（最初の3社、非公開価格）
- Proof 3件後：10〜15万円
- Proof + 数値成果後：20〜30万円
- 明確な専門性 / 紹介流入確立後：30〜50万円+

### 判定
**HOVELの最初の主商品として最有力。**

理由：
- Problemが分かりやすい
- Founder / Marketing責任者がBuyerになれる
- 商談数が少ない会社でも実施できる
- Before / Afterを実績化しやすい
- Win/Lossより初期顧客条件が緩い
- LPや営業資料まで意思決定を実装できる

### 判定
**最初の商品にはしない。Positioning Sprintからアップセルする。**

# 利益1,000万円モデルの再設計

低単価Sprintの件数勝負はしない。

到達モデル例：

## Buyer Intelligence Retainer
- 4社 × 30万円 / 月
- 年商 1,440万円

## Positioning Sprint
- 月2件 × 30万円
- 年商 720万円

## 合計
- 年商 2,160万円

仮に、外注・respondent費・ツール等の直接原価が売上の30%、その他固定費が年間300万円なら、

- 売上：2,160万円
- 直接原価：約648万円
- 固定費：約300万円
- 事業利益：約1,212万円

利益1,000万円を超える。

これは現時点ではForecastではなく **成立条件を確認するためのTarget Economics**。

# このモデルの最大リスク

## 1. 顧客アクセス

見込み顧客5〜8名を毎回HOVELだけで集めると、時間・報酬コストが高くなる。

対策：
- 基本はクライアント保有顧客 / 商談候補へのアクセスを優先
- 外部リクルーティングは有料Option
- respondent costは原価計算で分離

## 2. Positioningに30万円払う理由

実績なしでは弱い。

対策：
- 最初の3件はFounding Pilot
- Before / Afterを必ず測る
- LP CTR、CTA CVR、商談反応、訴求理解などをProof化

## 3. 作業受託化

LPコピー作成会社になってしまう可能性。

対策：
- コピーそのものではなく「Positioning Decision」を主成果物にする
- 実装は必要最小限

## 4. 継続契約が本当に売れるか

Buyer Intelligence Retainerは未検証。

対策：
- Sprint終了時に次の未解決Questionが継続的に出るかを記録
- 同じ会社で月次一次情報が必要か実証してから商品化

# Go / No-Go基準

## 3件終了時

以下のうち3つ以上が成立すれば継続。

- 3社が有料で購入
- 平均Delivery時間が15時間以下
- 顧客が明確に意思決定を変更
- 1社以上が紹介
- 1社以上が継続支援を希望
- 10万円以上でも購入意向がある

成立しなければ、Customer Understanding全般に戻るのではなく、最も反応が良かったProblemへさらに狭める。

# 最終判断

**HOVELはビジネスを捨てる必要はない。ただし、現行の“Customer Understanding Sprintをそのまま商品として売る”設計は修正する。**

推奨：

> B2B Positioning & Message Validationを最初のWedgeにする。
>
> Customer Understandingは内部能力として維持する。
>
> 実績が蓄積したらWin/Loss / Buyer Intelligenceへ継続課金で拡張する。

この方が、利益1,000万円へ向かうための **単価・継続性・Proof・専門性** の4条件を満たしやすい。
