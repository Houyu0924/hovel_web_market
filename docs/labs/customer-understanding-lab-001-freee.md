# Customer Understanding Lab #001 — freee会計

Status: Draft / 実測前
Date: 2026-08-09
Owner: HOVEL

## 目的

HOVELのCustomer Understanding Sprintの公開実績第1号として、freee会計を題材に「顧客理解 → 訴求仮説 → 公開 → 実測 → 改善」の一連の流れを検証する。

このLabの主目的はアフィリエイト収益そのものではない。顧客のProblemを起点に訴求を設計し、実際のクリック・申込行動で仮説を検証できる公開Proofを作ること。

## 今回の検証仮説

### Main Hypothesis

freeeを選ぶ理由は「機能が多いから」ではなく、ユーザーが抱える経理・確定申告上のProblemの強さによって決まる。

### Hypothesis A — 確定申告の不安

対象：初めて確定申告をする個人事業主・副業事業者。

Problem：
- 何を記帳すればよいか分からない
- 申告方法を間違えそうで怖い
- 税務用語が難しい
- 申告直前に慌てたくない

欲求：
- 自分でも迷わず申告まで進めたい
- 必要な作業を順番どおり処理したい
- 「これで合っている」という安心感がほしい

主な障壁：
- 会計ソフト自体が難しそう
- 有料サービスにする必要性が分からない
- 他の会計ソフトとの違いが分からない
- 導入後に使いこなせるか不安

## 訴求案 A

### 仮タイトル

**初めての確定申告で「何からやればいいか分からない」人へ。会計ソフトで不安を減らせるか検証してみた**

### 導入

初めて確定申告をするときに困るのは、計算そのものよりも「何を、どの順番で、どこまでやれば終わるのか」が見えないことです。

領収書、売上、経費、口座、クレジットカード、青色申告、電子申告。調べるほど言葉が増えて、結局どこから手を付ければいいか分からなくなります。

そこで今回は、HOVEL自身も将来的な導入候補として見ているfreee会計を題材に、**確定申告の不安をどこまで減らせるのか**という視点で整理します。

機能一覧を並べるのではなく、「初めて申告する人が実際に困る場面」に沿って見ていきます。

## 本文構成 v0

### 1. 初めての確定申告で本当に困ること

候補Problem：
- 何を記録するのか分からない
- 経費にしてよいものが分からない
- 銀行・カード・現金がバラバラになる
- 申告書の作り方が分からない
- 最後にミスしていないか不安

ここでは「会計ソフトが必要」という結論から始めず、まず作業上の不安を分解する。

### 2. freee会計はどのProblemを減らせるのか

評価軸：
- 日々の記帳負担
- 銀行・カード取引の整理
- 申告書作成までの導線
- 初心者が迷うポイント
- 自動化できる範囲
- 人間が判断しなければならない範囲

※公開前に、freee公式の最新機能・料金・対象プランを再確認する。

### 3. 逆に、freeeを入れても消えない不安

ここを必ず書く。

例：
- 何が経費になるかという税務判断
- 自分の取引の分類
- 複雑な税務処理
- ソフトを使い始める初期設定

「入れれば全部解決」とは言わず、適合する顧客と適合しない顧客を分ける。

### 4. どんな人なら導入価値が高いか

仮説：
- 初めて確定申告する
- Excelや手入力の管理が続かない
- 銀行・カード取引が増えている
- 経理作業に時間を使いたくない
- 年末や申告期に一気に処理したくない

### 5. どんな人にはまだ不要か

仮説：
- 取引件数が極端に少ない
- 既存の管理方法で困っていない
- 税理士側の指定システムがある
- 費用を払ってまで時間短縮する必要がない

### 6. HOVELならどう判断するか

HOVEL自身の導入判断軸：
- 毎月の記帳時間がどれだけ減るか
- 売上・経費の把握が速くなるか
- 確定申告時の作業量が減るか
- 月額費用より削減時間の価値が大きいか
- 将来の事業規模拡大にも耐えられるか

現時点では「導入確定」ではなく、比較対象として検証する。
