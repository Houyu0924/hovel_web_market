# HOVEL note KPI Dashboard v1.0

更新基準日: 2026-08-08

## North Star

**1,000ビューあたりの収益額（note Revenue per 1,000 Views）**

初期目標: **¥3,000 / 1,000 views**

計算式:

`Revenue per 1,000 Views = note由来収益 ÷ noteビュー × 1,000`

## 勝ち記事の定義

以下のいずれかを満たす記事を **Winner** とする。

- 公開後30日で50ビュー以上
- スキ率8%以上
- 商品リンクCTR5%以上
- 商品クリック3件以上
- 注文1件以上

### Strong Winner

以下のいずれかを満たす場合は、関連記事・比較記事・MVP導線を優先追加する。

- 注文2件以上
- Revenue / 1,000 Views が ¥3,000以上
- 商品リンクCTR10%以上
- 同一Problemの記事2本以上がWinner

## Old Spiceクラスターの暫定評価

現時点ではOld Spice関連が、HOVELで最も明確な購買行動シグナルを出している可能性が高い。

### 仮説

- 読者は抽象的な仕事術より、具体的な商品選び・香り・使用シーンに反応しやすい可能性がある
- 「日本人に合うか」「どれを選ぶか」「職場で使えるか」のような文脈は、一般的な商品紹介より棲み分け余地がある

### 判定保留条件

以下を満たすまではStrong Winnerとは判定しない。

- クラスター別トラッキングIDでクリックを再現
- 30日で商品クリック10件以上
- 1件以上の注文、または高CTRを確認

---

## Stop Rule

公開30日後に以下すべてを満たす記事は、追加投資を停止する。

- 20ビュー未満
- スキ0
- 商品クリック0

ただし、検索順位上昇中・季節要因・新規記事でデータ不足の場合は保留可。

## 経営ルール

- ビューだけでは成功判定しない
- 記事数だけをKPIにしない
- Winnerが出たProblemへ追加投資する
- 売れないテーマを惰性で増やさない
- Amazonは当面、収益源であると同時に購買意図センサーとして扱う
- 計測できない導線は改善対象とする
- 2026-08-08以前のAmazonクリックはOld Spice由来に偏っている可能性が高いため、全体CTRの評価には使わない
