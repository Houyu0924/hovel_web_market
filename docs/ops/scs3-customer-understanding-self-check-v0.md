# SCS★3 顧客理解セルフチェック v0

作成日: 2026-08-09
目的: HOVELの市場検証用。SCS★3取得可否を判定する公式チェックリストではない。集客・顧客理解・送客/収益化の共通入口として使用する。

## 0. 重要な前提

- SCS評価制度の★3・★4は2027年3月頃の運用開始予定。
- ★3は「専門家確認付き自己評価」。取得希望組織が自己評価し、所定要件を満たすセキュリティ専門家が確認・助言・署名する。
- 制度は任意。取得の要否は取引当事者間の契約・要求水準による。
- ★3・★4要求事項・評価基準は公開済みだが、詳細な評価方法・ガイダンスは今後具体化される。
- SECURITY ACTIONはSCS準備段階としてIPAが案内している。

このフォームでは「★3を取得できる/できない」は表示しない。
表示するのは、準備状況・不確実性・次に確認すべき事項だけ。

## 3. 回答後に表示する結果

### A. 緊急度
High:
- 取引先から要求あり
- 期限6か月以内

Medium:
- 今後要求されそう
- 期限1年以内 / 未定

Low:
- 要求なし / 情報収集段階

### B. 準備負荷
High:
- 担当者なし
- SECURITY ACTION未対応/不明
- 困りごと3個以上

Medium:
- 兼任担当者
- 一部対策あり

Low:
- 専任/外部担当あり
- 既存の管理体系あり

### C. 推奨Next Action
1. まず公式情報を確認する
2. SECURITY ACTIONを準備段階として確認する
3. ★3要求事項・評価基準と自社現状の差分を整理する
4. 必要なら制度要件を満たす専門家への相談を検討する

※「あなたは★3取得可能です」等の断定はしない。

## 5. 30日検証KPI

最初の目標は売上最大化ではなく「市場の痛みを確認しつつキャッシュ導線を作れるか」。

### 最低ライン
- 有効回答: 30件
- ターゲット企業への直接ヒアリング: 10件
- 支援ベンダー/専門家ヒアリング: 10件

### Goの目安（仮説）
以下のうち3つ以上:
- Trigger率 30%以上
- 6か月以内Deadline率 20%以上
- Comparison Intent率 30%以上
- 外部支援ニーズ 40%以上
- ベンダー側で「紹介/見込み顧客獲得に対する支払意思」3社以上

### Kill / Pivot
- 30件集めても具体的Triggerがほぼ存在しない
- 支援先比較ニーズが弱い
- ベンダー10社中支払意思ゼロ
- 集客1件あたりの手作業が恒常的に重い
- 制度スケジュールが大幅変更される

## 7. 初期運営ルール

- 制度の義務化を示唆しない。
- 「取得しないと取引停止」等の恐怖訴求をしない。
- 公式制度とHOVELのサービスを明確に区別する。
- 制度変更があれば質問・結果表示を更新する。
- 個人情報は必要最小限。初期は会社名・氏名を必須にしない。
- 相談希望者だけ連絡先を任意取得する。
- 週次作業上限を5時間に置く。
