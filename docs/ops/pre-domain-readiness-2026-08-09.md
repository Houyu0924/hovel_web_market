# HOVEL 独自ドメイン取得前に進める準備

Date: 2026-08-09
Status: Active

## 結論
独自ドメイン取得は月末まで保留してよい。HOVELの検証は止めず、ドメイン不要の準備と営業設計を先に進める。

## 今すぐ進める

### 1. 営業先の優先順位
WIPは3社まで。
1. InfraAcademy
2. Saix
3. sai X aid

反応がなければ Uravation → THUNDER → リベルクラフト の順に差し替える。

### 2. 送信前に固定するHOVEL説明
**営業を増やす前に、なぜ売れないのかを顧客から特定します。**

HOVEL Customer Understanding Sprintは、顧客・見込み顧客・失注情報を使って、価格・訴求・ICP・Proofのうち次に変える3つを決める。

### 3. Problem Interview
最初の15分は販売ではなくProblem確認。
確認項目:
- 反応が良い顧客像
- よく出る質問
- 説明し直す箇所
- 価格で止まるか、価値理解で止まるか
- 今一番判断に困っていること

### 4. 有料化条件
Problemが確認できた企業にのみPilotを提示する。
- Pilot: 30,000円
- 通常テスト: 50,000円
- 期間: 7〜10日
- 納品: Customer Understanding + 次に変える3つ

### 5. 事務準備
ドメインがなくても先に準備する。
- 屋号表記: HOVEL
- 見積書テンプレート
- 請求書テンプレート
- 売上・経費の記録方法
- 契約時に確認する支払条件
- 公開実績への掲載可否確認文

## ドメイン取得後にやる
- hovel-lab.com取得
- contact@hovel-lab.com などの独自メール作成
- SPF / DKIM / DMARC設定
- 営業署名を独自メールへ統一
- Saix等、フリーメール不可の窓口へ送信

## 今はやらない
- 法人化
- インボイス登録
- 大規模LP制作
- 大量営業
- 複数サービスへの商品分割

これらは初回売上または契約上の必要性が確認されてから判断する。
