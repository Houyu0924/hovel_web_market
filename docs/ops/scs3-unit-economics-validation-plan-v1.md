# SCS★3 Unit Economics Validation Plan v1

Date: 2026-08-09

## Objective
30日以内に、SCS★3関連の比較・送客モデルで「1件の有効顧客情報にベンダーがいくら払うか」を実測する。

最重要KPIはアクセス数ではなく、Qualified Leadあたりの支払意思（WTP）。

## Core Hypothesis
支援ベンダーが、以下の条件を満たす見込み顧客に対して有償で接点を持ちたいなら、比較・送客モデルは成立する。

Qualified Leadの仮定条件:
- 法人
- SCS★3または取引先要求に関連する具体的な課題がある
- 導入・対応時期が12か月以内
- 担当部署または決裁関係者が特定できる
- 支援会社への相談意思がある

## Price Test
市場相場を断定せず、以下をテスト価格として提示する。

- Test A: 5,000円 / lead
- Test B: 15,000円 / lead
- Test C: 30,000円 / lead
- Test D: 月額50,000円 / 3 leadsまで

最初の目的は最大単価ではなく、実際に「払う」と言う価格帯の発見。

## 30-Day Validation Targets
### Buyer side: 支援ベンダー
- 候補抽出: 30社
- 接触: 20社
- ヒアリング: 10社
- 価格提示: 10社
- 有償テスト合意: 2社以上

### User side: 中小企業
- セルフチェック回答: 30件
- 顧客ヒアリング: 10件
- Qualified Lead: 5件以上

## Questions for Vendors
1. 現在、SCS関連の案件をどう獲得しているか
2. 1件の新規商談獲得に実質いくら使っているか
3. どの条件が揃えば「有効リード」と判断するか
4. どの条件なら不要リードになるか
5. 新規商談1件に対して最大いくら払えるか
6. 固定掲載、成果報酬、リード単価のどれが買いやすいか
7. 月何件なら受け入れ可能か
8. 既存の比較サイト・紹介会社への不満は何か

## Cash Model
300万円の年間運転資金目標に対し、まずこのチャネル単独で年間120万円を再現できるかを検証する。

例:
- 1.5万円 / lead × 月7件 × 12か月 = 126万円

または

- 月5万円スポンサー × 2社 × 12か月 = 120万円

現段階では仮説。販売合意が得られるまで事業計画上の確定売上にはしない。

## Time Budget
可処分時間を守るため、検証期間中も上限を設定する。

- 週5時間以内
- 企業ヒアリング: 30分/件
- ベンダーヒアリング: 30分/件
- コンテンツ制作: 原則1ページのみ
- DB開発・システム開発: 禁止
- SEO記事量産: 禁止

## Go / No-Go
### GO
以下のうち2つ以上:
- 2社以上が有償テストに合意
- 1 leadあたり15,000円以上の明確な支払意思
- 月5万円以上のスポンサー支払意思
- Qualified Leadの生成を週2時間以内で再現可能

### CONDITIONAL GO
- 支払意思はあるが単価が5,000〜15,000円
- 顧客側ニーズは強いがLead生成コストが高い

この場合はスポンサー/レポート/成約課金など別収益を追加検証する。

### NO-GO
以下のいずれか:
- 10社提示して有償テスト0社
- 支払意思が5,000円未満に集中
- 有効Lead生成に1件2時間以上かかる
- 顧客側の課題が制度開始待ちで顕在化しない

## Next Single Task
支援ベンダー候補30社を抽出し、そのうち最初の10社にヒアリング兼価格テストを行う。

この検証が終わるまで、別市場の選定、新規SaaS開発、記事量産には進まない。
